# Decision records

One file per decision that outlives its ticket, named `NNNN-short-title.md`.

- **accepted** records are binding.
- **proposed** records are context, not rules.
- **superseded** records are history. Mark them; do not delete them.

If a task conflicts with an accepted record, stop and raise it: either the
task or the record has to change. Git history is the changelog; keep each
record to its current text.
